- 목적: 사후 합리화 방지. 어떤 결과가 나오든 아래 규칙을 그대로 적용한다.

## 1. 비교 대상

| 변형 | 구성 | 추론 추가비용 |
|---|---|---|
| 기준선 | prep 없음 / aug=medium | 0 |
| **A** | prep 없음 / **aug=robust** | **0** |
| B | **prep=gray+spec** / aug=medium | 전처리 시간 |
| C | prep=gray+spec / aug=robust | 전처리 시간 |

전부 256px, 동일 분할(fold0~4), 동일 시드 42.

## 2. 판정 축

Stage 0에서 붕괴가 확인된 3축만 판정 대상으로 한다. 기하 축(회전·이동·스케일)은
이미 강건하므로 판정에 쓰지 않는다.

| 축 | 최대 강도 | 기준선(256px) AUROC | 기준선 재보정 미검율 | 기준선 과검율 |
|---|---|---|---|---|
| 색바램 | 30% | 0.8924 | 39.2 % | 65.7 % |
| 황변 | 30% | 0.9018 | 37.4 % | 81.5 % |
| 정반사 | 면적 10% | 0.8273 | 56.3 % | 100.0 % |

## 3. 합격 조건 (3축 **전부** 충족해야 그 변형이 "회복"으로 인정)

1. 최대 섭동에서 **AUROC ≥ 0.95** (DoD §1.3 기준선)
2. 최대 섭동에서 **재보정 τ 미검율 ≤ 5%** (DoD 미검율 기준)
3. 최대 섭동에서 **고정 τ 과검율 < 50%** — 판정기가 기능을 유지한다는 최소 조건
   (100%는 전 샘플 NG 판정 = 기능 정지)

### 부가 조건 (모든 변형 공통)

4. **무섭동 AUROC ≥ 0.99** — 강건성을 얻으려고 깨끗한 성능을 무너뜨리면 안 된다
   (기준선 0.9992, 허용 손실 약 0.01)
5. **단일 스레드 e2e p50 ≤ 100 ms** (DoD §1.3). 전처리 비용 포함, 무경합 측정치 기준

## 4. 선택 규칙

```
if A 합격:
    → A 확정. 전처리 불필요.
      B/C가 A보다 나아도, 3축 전부에서 최악축 AUROC를 +0.02 이상
      개선하지 못하면 전처리 비용을 정당화하지 않는다.
elif B 또는 C 합격:
    → 합격한 것 중 단일 스레드 e2e p50 이 가장 낮은 설정을 채택.
      전처리 필요로 결론.
else:
    → 값싼 처방으로는 불충분. Stage 2(DINOv2 증류 등) 검토 근거 성립.
      단 DoD 재협상이 전제임을 함께 기록한다.
```

**동률 처리**: A와 C가 모두 합격하고 C가 +0.02 이상 우위면, 지연 예산이 허용하는 한
C를 채택하되 A를 경량 대안으로 병기한다.

## 5. 해상도 재검토 조건

Stage 0에서 640px가 섭동 하에 일관되게 우수했다(황변 0.9654 vs 256px 0.9018).
256px에서 합격한 변형이 없으면 384/640으로 동일 변형을 재학습해 판정한다.
256px에서 합격했다면 해상도는 256으로 유지한다.

## 6. 판정에 쓰지 않는 것

- **홀드아웃** — P5 STOP-GATE 2 전용. Stage 1 판정에 절대 사용하지 않는다.
- 단일 fold 결과 — 5-fold 평균 ± 표준편차로만 판단한다(§7.4).
- 0.01 미만의 AUROC 차이 — fold당 val 불량이 15~16장이라 유의하지 않다.

## 7. 결과와 무관하게 기록할 것

- robust 증강을 쓴 변형(A·C)은 시험 섭동과 **같은 축**을 학습에서 겪었다.
  범위는 더 좁게 뒀으나(채널 게인 ±15% vs 시험 30%, 정반사 ≤3% vs 시험 10%),
  이 개선은 **분포 내 강건성**이며 미지 변동에 대한 일반화가 아니다.
- 모든 수치는 val fold 기준이며 τ도 같은 val에서 정해 낙관적으로 편향돼 있다.
- 합성 섭동은 실제 라인 변동의 **대리**다. 섭동 모형이 현장과 다르면 결론도 달라진다.
